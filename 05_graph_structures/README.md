# Chapter 05 — Graph Structures  
## Relationship Modeling in AI

## Goal

Understand how graphs represent complex relationships.

Unlike trees, graphs allow:
- arbitrary connections
- cycles
- many-to-many relations

This makes them ideal for modeling real-world AI problems.

---

## Data Structure Concepts

- Node
- Edge
- Path
- Connectivity

---

## AI Mapping

Graphs are central in:

- Knowledge Graphs
- Graph Neural Networks (GNNs)
- Recommendation Systems
- Social Network Analysis
