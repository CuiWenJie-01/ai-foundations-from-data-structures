# Chapter 05 Report — Graph Structures

## 1. 实验回顾

本章通过最短路径搜索，
展示了图结构最核心的能力：

> 在复杂关系网络中寻找连接路径。

实验中：
- 每个节点代表对象
- 每条边代表关系
- AI 的任务是找到最优连接路线

---

## 2. 关键观察

### 2.1 图不是层级，而是网络

树是：

```
父 → 子
```

| 图概念           | AI 中含义  |
| ------------- | ------- |
| Node          | 实体 / 概念 |
| Edge          | 关系      |
| Path          | 推理链     |
| Shortest Path | 最优关系解释  |

---
## 输出结果
```
从 A 到 G 的最短路径:
```
