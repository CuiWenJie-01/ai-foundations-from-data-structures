# Chapter 05 Report — Graph Structures

## 1. 实验回顾

本章通过最短路径搜索实验，
展示了图结构在 AI 中最核心的能力：

> 在复杂关系网络中寻找最优连接路径。

实验里：

- 每个节点（Node）代表一个对象；
- 每条边（Edge）代表对象之间的关系；
- AI 的任务不是孤立判断单个节点，
  而是在整个关系网络中找到最合理的路径。

这和前面的树结构非常不同：

- 树强调层级决策；
- 图强调关系连接。

这一章开始，AI 真正进入：

> **“理解关系”而不是“单点分类”。**

---

## 2. 关键观察（重点看关系，而不是节点）

### 2.1 图不是层级结构，而是关系网络

树结构是：

```text
父节点
├── 子节点1
└── 子节点2
```
它天然强调：

从上到下的层级组织。

而图结构不同：
```
A ↔ B
A ↔ C
B ↔ E
C ↔ F
E ↔ F
F ↔ G
```
它允许：

任意节点互相连接；
多对多关系；
回路存在。

这意味着：

图比树更接近真实世界。

现实中的知识、社交关系、推荐系统，
几乎都不是树，而是图。

2.2 路径本身就是推理结果

在树结构里：

通常重点是叶子节点答案。

例如：

最终分类 = Yes / No

但图结构里不同：

图中的“路径本身”就是答案的一部分。

例如：

A → C → F → G

这条路径不仅告诉我们：

能到达 G，

还告诉我们：

是如何到达的。

这在 AI 中极其重要，因为：

推理链 = 可解释性。

2.3 同一目标可能存在多条可行路径

图最大的特点之一：

同一个目标往往不止一条路。

例如从 A 到 G：

可能有：

A → C → F → G

也可能有：

A → B → E → F → G

这意味着：

AI 不只是判断能不能到达；
还必须决定哪条路径更优。

这就是最短路径问题的本质。

2.4 BFS 为什么天然适合最短路径

本实验采用 BFS：

因为 BFS 的特点是：

一层一层扩展搜索。

它保证：

第一次找到目标，
就一定是最短路径。

这让我理解：

搜索策略决定推理质量。

同一个图：

不同算法，
得到不同效率。
