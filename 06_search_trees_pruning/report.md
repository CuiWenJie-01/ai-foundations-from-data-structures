# Chapter 06 Report — Search Trees & Pruning

## 1. 实验回顾

本章实验比较了两种搜索方式：

1. 线性扫描（Linear Search）
2. 二分搜索（Binary Search，体现 BST 思想）

它们完成的是同一个任务：

> 在同一组数据中找到目标值。

虽然结果完全一致，
但它们的搜索路径和效率差异巨大。

这正是本章最重要的观察点：

> **结构不同，搜索成本完全不同。**

---

## 2. 关键观察（重点不是结果，而是搜索过程）

### 2.1 线性搜索：暴力方法的本质

线性搜索采用最直接的方法：

> 从头开始，一个一个检查。

它没有利用任何额外信息：

- 不关心数据是否有序
- 不提前排除任何候选
- 每个元素机会完全平等

这意味着：

> 当数据规模变大时，成本线性增长。

在 AI 中，这对应：

- 暴力枚举推理
- 穷举候选搜索
- 无剪枝路径探索

它保证正确，
但效率极低。

---

### 2.2 二分搜索：结构带来的巨大优势

二分搜索并不是“算得更快”，

而是：

> **每一步都主动减少问题规模。**

每次比较中间值后：

- 一半空间直接排除
- 永远不再检查

这意味着：

```text
10000 个候选
↓
5000
↓
2500
↓
1250
```
## 对应的 AI 概念
| 搜索树概念    | AI 含义  |
| -------- | ------ |
| 排序结构     | 先验组织信息 |
| 二分搜索     | 剪枝决策   |
| 剪掉半边     | 搜索空间裁剪 |
| O(log n) | 高效推理路径 |
